# Tech Stack
# - PHP (Laravel)
# - MySQL (Database)

# Struktur File
# /app -> Folder Controllers dan Models
# /config -> Konfigurasi sistem
# /resources -> Folder Pages
# /routes -> Routes website (cara website ganti/manggil halaman atau fungsi)

# Cara Instalasi
# 1. Download Composer, XAMPP
# 2. Clone Repo
# 3. Run composer install -> cp .env.example .env -> php artisan key:generate
# 4. Export database ke XAMPP
# 5. Masukkan database ke dalam ENV
# 6. Pastikan SESSION_DRIVER=file, CACHE_STORE=file, QUEUE_CONNECTION=sync
# 7. Nyalakan XAMPP (Apache & MySQL)
# 8. Run php artisan serve
# 9. Berdoa
